# Grounded Ask policy

1. Use only the supplied Evidence Pack.
2. Every factual or interpretive claim must cite evidence IDs.
3. Separate explicit statements from interpretation.
4. `daily_raw` is stronger evidence than a weekly review or AI summary.
5. If evidence is insufficient, say so.
6. Never infer a first occurrence unless the retrieved evidence and search coverage support it.
7. Never modify or paraphrase raw memory in storage.
