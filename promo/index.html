纸格，跟着思路走。

拖动和缩放纸格，用吸附对齐理清版面。添格、隐藏、恢复，也可以应用常用布局。

02 / 留存

未写完的，也留得住。

文字、未提交的附件、字体与布局保留为本地草稿。收笔保存后，再次修改会留下版本。

漂流瓶会自动发给别人吗？

漂流瓶是保存在本机、写给未来自己的内容。LifeOS 运行时可提醒到期来信；完全退出后，下次打开再补查。它不参与日记检索、AI 或公开纪念页。

桌宠聊天会读取日记吗？

不会。桌宠聊天使用当前聊天内容和按需匹配的公开产品指南。日记问答则是另一项功能，先查看与选择证据，再确认调用模型。

第一次使用，需要配置 AI 吗？

不需要。可以直接写日记、翻阅旧页、使用记忆抽签和桌面伙伴。诗歌推荐等 AI 功能需要按需配置服务；是否启用由你决定。

升级后，以前的日记还在吗？

升级保留本地工作区。仍建议定期备份工作区，在更新前留一份自己的副本。v0.5.2 的彩笺同样保存在本机。

安装前，有什么需要知道？

安装包包含运行环境，无需另装 Python 或 Node.js。Windows x64 社区构建未做代码签名；macOS 11+ 构建为 ad-hoc 签名、未经 Apple 公证。请从官方 Release 下载并查看校验信息。Ollama 与大模型不包含在安装包中。
