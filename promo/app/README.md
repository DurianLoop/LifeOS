# LifeOS · 随身档案 v0.6.1

入口：https://lifeos-diary.netlify.app/app/ 。使用原生 HTML/CSS/JavaScript、IndexedDB 和 Service Worker，无账号、在线字体或前端运行时依赖。源码分支为 `codex/pocket-completeness`。

## 写作与翻阅

- 日记和 ISO 周记；日记、日程、心得摘录、自我探索、体系构建、习惯六种写作格，也可切换整页文字。
- 多份自动草稿、标签、彩笺收藏、附件；写入事务完成才显示收笔成功。关闭写作会先收下草稿。
- 日期、月份、日历、全文和标签筛选；最近 30 个修改版本可以恢复，恢复前的内容仍进入历史。
- 阁楼展示写作概览、时间线、标签和星期节律；往年今日、记忆抽签及答案来源均可回到原文。
- 时间漂流瓶支持文字和照片/音视频附件；浏览器允许时可主动录音。未到期正文在界面收起，到期后在应用打开时提示。时间约定不是密码保护，不提供后台定时推送。
- 本地诗选和收藏；ViVi、DSH 小鲸 106 个原始动作；六段自然声、音量、15/30/60 分钟定时和暂停。
- 暖纸、晨雾、夜读；正文 16–24px、行距、宋体/黑体和减少动效。

## 本机数据、备份与恢复

继续使用旧版的 `lifeos-mobile` 数据库，原地升级到版本 2，保留原记录和未收笔草稿。日记、附件、草稿、版本、收藏、信件及 AI 回答保存在当前浏览器。Safari 与主屏幕应用可能使用不同存储；清理网站数据、删除应用或系统回收都可能丢失内容。持久存储申请不能代替备份。

设置中可导出完整 JSON 备份或密码备份。完整备份包含附件字节、历史、草稿、信件和收藏，不包含 API Key、AI 服务配置。密码备份使用 PBKDF2-SHA256（310,000 次）与 AES-256-GCM，解密校验通过才允许导入。密码无法找回；本机数据库本身未额外加密。

导入先检查格式、附件 SHA-256 与引用完整性，再预览；确认后通过一个事务提交。冲突可以保留本机原文，或采用导入内容并将原文留为历史。预览后原库发生变化时会要求重做预览。已有相同 ID 的草稿/信件/AI 资料和已有偏好优先保留本机版本，请保留原备份文件；不同 ID 的补充资料会一并导入。多份重叠备份须分别恢复。旧版本页面占用数据库时会提示先收笔并关闭旧页。

限额：20,000 条记录，正文 200,000 字符，单个附件 50 MB，单次导入文件总量 300 MB。完整备份在内存组装，大量媒体建议分批管理，导出后应实际打开检查文件。

### 与电脑交换

支持电脑的日记/周记 JSON，以及「Markdown → 包含附件」导出 ZIP；也支持旧手机备份、Markdown、TXT、HTML、CSV 和 Day One JSON。桌面 JSON 中完整 Markdown 原文会保留，包含原来的元数据前言。外来 HTML 转为文字，不执行脚本。ZIP 进行路径、大小和 CRC 检查；数据库恢复 ZIP 应在原生应用恢复。

「导出日记 JSON」只交换日记/周记文字、日期和标签，不包含附件字节、手机版修订身份或回收站。需要完整手机恢复时使用完整备份。网页、桌面和原生手机应用数据独立，文件交换不等于自动同步；网页也不运行完整桌面分析引擎、系统托盘或桌面悬浮窗。

## AI 按需使用

填写自己的 DeepSeek、OpenAI 或通义千问（中国站）配置；API Key 仅保留当前页面内存，刷新后重填。人生问答先选择 1–6 页记录，再预览并编辑摘录，确认后才经本站固定网关发送；问题最多 2,000 字符，摘录累计最多 10,000 字符。答案及来源可保存在本机，模型判断仍需核对原文。伙伴聊天只发送明确的聊天轮次，不读取日记。

网关仅允许这三家固定地址，未使用站点共享 Key，不主动记录正文与密钥，问答响应禁止缓存。Netlify 与相应服务商参与处理；模型费用和数据政策由服务商决定。停止等待会取消浏览器请求，但服务商可能已收到内容。

## 安装与离线

iPhone：用 Safari 打开，等待「离线已就绪」，通过分享菜单添加到主屏幕。Android 可通过浏览器安装菜单安装。首次完整缓存后，写作、阅读、检索、备份和本地诗选可离线使用。动画和声音首次访问时缓存，只能离线访问已缓存的媒体。AI 需要联网。新版本等待旧页面关闭后激活，不强制刷新正在写作的页面。

## 开发与验收

在仓库根目录执行：

```sh
npm ci --prefix tests --ignore-scripts --no-audit --no-fund
node --test --experimental-test-isolation=none tests/mobile-model.test.mjs tests/mobile-sw.test.mjs tests/mobile-ask.test.mjs tests/pocket-workspace.test.mjs
node promo/build.mjs
node promo/serve.mjs
```

`LIFEOS_PROMO_PORT` 设置端口，`LIFEOS_PROMO_DIST=1` 预览构建产物。开发时 `/app/?preview=1` 跳过 Worker 注册。正式离线检查使用构建产物：等缓存完成、停止预览服务、刷新，再新写并重读。测试仅使用合成数据。

v0.6.1 已完成数据库升级/事务回滚/并发冲突/完整附件备份/密码和篡改/ZIP 的自动检查，以及浏览器写作、附件、版本恢复、空库导入、断服务刷新并保存周记验收。iPhone 实机 Safari、麦克风录音和真实付费模型请求尚未在本机验收，不以桌面浏览器代替实机结论。
