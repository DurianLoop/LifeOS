# LifeOS v0.6.2 · Mac 桌面一致性

Mac 沿用 Windows 的完整桌面工作区：左侧导航、六格书桌和自由布局、章法模板、流年书页与彩笺、原文搜索、拾诗、星轨记忆抽签、漂流瓶、伙伴、阁楼和全部工具目录。

两端打包同一套页面、样式与功能代码，随包提供完整字库的 Noto Serif SC 与 Noto Sans SC（SIL OFL 1.1），统一文字度量、字重、表单和滚动条。保持原有纸色、灰紫强调、字号设置与阅读节奏。macOS 原生菜单新增落笔、寻迹、导入、导出与界面设置，使用 Cmd 快捷键；日记和草稿仍保存在用户自己的工作区。

Mac 提供 Apple Silicon（arm64）与 Intel（x64）的 DMG 和 ZIP。源码包括相同窗口尺寸下的 Windows/Mac 页面与工具目录验收、保存和正常重启后的恢复检查。布局一致性按 CSS 像素比较；不同系统的文字抗锯齿不作逐像素相同承诺。

这是 ad-hoc 签名的社区构建，尚未取得 Apple Developer ID 公证。macOS 11 及以上可用；首次打开时可能需要在系统设置的“隐私与安全性”中允许。相机、麦克风授权需在实际设备上确认。

本次发布聚焦桌面端。Android 与 iOS 源码/模拟器继续使用 v0.6.1。DSH 小鲸素材保留上游非商业许可；开源字体许可随包附带。
