# LifeOS v0.4.2

桌面端重启时使用不同端口，可能让未提交草稿和部分偏好变得不可见。v0.4.2 将这些状态保存在固定工作区，并补齐附件草稿、关闭保护、更新操作与备份恢复流程。

## 主要修复

- 草稿、未提交附件、纸格布局、字体和侧栏偏好跨重启保留；自动找回旧端口下的草稿
- 保存状态与实际写入结果一致；关闭窗口前检查保存，失败时可返回编辑；正式保存重试避免重复附件
- 日记文件与版本数据库之间增加中断恢复记录，提交失败恢复原文，提交成功保留新版本
- 备份包含草稿、附件与偏好，先校验、重启后再应用；恢复中断时回退，安全备份继续显示在列表中
- 更新支持检查、下载、取消、重试和重启安装；安装前保存草稿并创建安全备份
