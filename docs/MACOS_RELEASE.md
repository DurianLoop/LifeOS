# macOS desktop release

macOS and Windows package the same `app/` renderer, backend, engine, importers, connectors and marketplace. Mac is a native Electron application with its matching embedded Python runtime; it does not load the hosted website. The desktop renderer explicitly requires the native preload bridge and cannot select Android/iOS navigation from a Mac user agent.

v0.6.2 bundles Noto Serif SC, Noto Sans SC and Noto Sans Mono with full upstream glyph coverage and variable weights 400–700. Their licenses and SHA-256 provenance are in `app/fonts/`. Both desktops use the same type metrics, controls and scrollbars, retaining the Windows paper desk and existing typography preferences. Native macOS App, File, Edit and Window menus map to existing desktop actions and Cmd shortcuts.

The workflow builds arm64 on macOS 15 and x64 on macOS 15 Intel. Each package contains Python 3.13.16 from the pinned python-build-standalone release, verified before installation. The app, native libraries and helpers receive ad-hoc signatures. This community distribution has no Developer ID or notarization; macOS 11 or newer is required. Install the DMG by dragging LifeOS to Applications. ZIP is also available. First-launch Gatekeeper consent and actual camera/microphone consent require user-device verification. Upgrade community builds using the downloaded DMG; unattended installation has not been verified.

Private data stays in `~/Library/Application Support/LifeOS/workspace/`, outside the app. Packaging starts from an empty public Vault. Validation checks final archive contents, architecture, deep signatures, permissions, relocatable Python and the real bundled backend. It launches final main/preload in a visible native window using synthetic data, saves a journal, closes normally, relaunches and checks stable IDs, revision/file hashes and restored drafts.

`scripts/desktop_parity.cjs` records the complete desktop tool catalogue and actual layout/screenshot cases at common window sizes. `scripts/compare_desktop_parity.py` requires identical renderer hashes, bundled fonts, tool lists and layout geometry (one CSS pixel tolerance). Windows and both Mac architectures must supply evidence from the same source commit. Review screenshots as well: equal source hashes alone do not prove visual parity. OS text rasterization is outside the geometry comparison.
