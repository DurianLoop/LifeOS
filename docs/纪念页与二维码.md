# LifeOS 纪念页与二维码

## 页面里有什么

在桌面端「纪念页 / 二维码」写标题和前言，勾选要公开的日记，并把最多 12 篇标成精选故事。首次进入默认不选任何日记。访客打开页面后可以读精选故事、搜索完整的**已选公开档案**，也可以向基于这些文字的 AI 分身提问。

发布的是当时的文字快照，不包含附件；私有日记之后的改动不会自动公开。发布前可逐篇打开原文检查，点击发布时还会再次确认公开篇数。更新与撤下沿用同一网址，方便二维码长期指向同一页。撤下后旧二维码会显示页面不可用。

标题、前言、选篇和精选标记会保留为本机草稿，重新进入编辑页可以继续修改。候选列表支持搜索和分批加载。每次最多选择 5000 篇日记；Netlify 公开档案总大小上限为 4 MB，正文不会被静默截断，超过上限会提示减少选篇。某篇日记的原文版本文件丢失时会拒绝发布，请先恢复该版本或取消选择。

## 用 Netlify 免费部署

本项目提供 `netlify.toml`、`netlify/functions/memorial.mjs` 和 `memorial-site/memorial.html`。页面由 Netlify 托管；公开快照放在 [Netlify Blobs](https://docs.netlify.com/build/data-and-storage/netlify-blobs/) 的站点存储中，跨部署保存；提问使用 [Netlify AI Gateway](https://docs.netlify.com/build/ai-gateway/overview/)。不需要另购域名、数据库或模型 API 密钥。

1. 在 Netlify 登录现有账户，确认使用**新版按额度计费的 Free 套餐**。旧版免费套餐不能使用 AI Gateway。当前 Free 套餐每月有 300 credits 的硬上限；额度用尽后站点会暂停，次月恢复。部署、流量、函数、存储和 AI 都会消耗额度。
2. 从本项目目录使用 [Netlify CLI](https://docs.netlify.com/api-and-cli-guides/cli-guides/get-started-with-cli/) 部署：先安装依赖和 CLI，登录并创建/关联一个新 Netlify 站点，然后运行 `netlify deploy --prod`。站点构建设置使用仓库根目录的 `netlify.toml`，发布目录是 `memorial-site`。也可在 Netlify 从 Git 导入本仓库，根目录保持默认；首次正式部署后 AI Gateway 才会激活。
3. 在 LifeOS 的「纪念页 / 二维码」点击「生成发布密钥」，复制这次显示的密钥。在 Netlify 站点的 **Project configuration → Environment variables** 新增 `MEMORIAL_PUBLISH_TOKEN`，值粘贴该密钥。环境变量要提供给 Functions；修改后重新部署才会生效。密钥不要放在 Git、`netlify.toml` 或公开网页中。
4. 把 Netlify 站点地址（如 `https://your-site.netlify.app`）填回 LifeOS，点击「保存网址并检查连接」。确认连接正常后选择日记、精选故事、是否开放 AI，然后预览与发布。桌面端会显示公开网址与可下载的 SVG 二维码。

`cloud/dev_sync_server.py` 仍是本机开发服务，不是 Netlify 线上服务；纪念页的 Netlify 配置独立于 LifeOS「同步」账号。Windows v0.3 安装包已包含二维码组件；从源码运行时需安装 `requirements.txt` 中的 `qrcode` 依赖。

## 刻印前检查

用手机在不同网络下打开公开网址，并用两部手机测试二维码。Netlify 免费子域名依赖账号和站点持续存在，也受免费额度影响，不能保证多年后仍可访问。正式刻印如果要降低换平台时二维码失效的风险，之后可改用自己持有的域名；域名通常需要续费。

公开档案即使设为不让搜索引擎索引，拿到链接的人仍可阅读、复制、保存。发布前逐页检查姓名、联系方式、住址以及其他不想公开的经历。AI 分身的回答只依据公开快照，可能有误；站点对每个访客和全站设置了日提问次数限制，但并发访问仍可能多消耗额度。
