# LifeOS v0.3.0

这一版修复 Windows 桌面启动，并整合今日一诗、白噪音和纪念页 / 二维码。

## 桌面启动

- 修复安装版从 `app.asar` 内错误查找 Python 和后端资源的问题。
- 内置独立 Python；首次启动创建空白索引，用户无需另装 Python。
- 日记、修订和配置存放在 `%APPDATA%/LifeOS/workspace/`，升级保留数据。
- 自动避开被占用的端口；启动失败显示原因和本地日志位置。

## 今日一诗与白噪音

- 本地收录 39 首诗词，支持当日推荐、缘由、全文和历史；自动推荐默认关闭。
- 10 种本地合成环境音，支持播放、暂停、切换和音量记忆。
- 修复慢启动时诗句按钮不绑定、关闭自动后仍排队发送，以及音频切换、音量和页面退出的状态问题。

## 纪念页与二维码

- 选择公开篇目和精选故事，预览后显式发布文字快照；支持同网址更新、搜索、可选 AI 提问和撤下。
- 下载可打印的 SVG 二维码；撤下后停止提供有效公开页面及二维码下载。
- 修复草稿选篇丢失、篇目列表截断、长正文截断、缺失修订错误和未配置时的状态接口。
- 公开站点需要按 [配置说明](纪念页与二维码.md) 部署并设置发布密钥。发布 GitHub 版本不会公开个人日记。

## 验证与分发

运行 `python scripts/run_v03_release_checks.py --backend-python desktop/python-runtime/python.exe` 可复现本版聚焦检查。测试使用临时合成数据和模拟 AI；不会发送真实日记。打包后可以通过 `scripts/test_desktop_backend.py --resources <resources目录> --python <内置Python>` 验证实际包内资源。

Windows x64 安装器随 Release 提供，附 SHA-256 校验文件。此版本未进行代码签名；其他系统可从源码运行，未提供其安装包验证。
