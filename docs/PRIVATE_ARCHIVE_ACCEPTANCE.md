# 本地日记全量验收

本轮以用户提供的 Markdown ZIP 完整副本进行测试。原 ZIP、正常使用的 Vault 和桌面用户目录保持原状；隔离副本、导出文件、日志和截图保存在 Git 忽略的本机验收目录。报告只记录数量、耗时和结果，不保存日记正文。

## 修复与升级

- 支持日记与周记混合导入。周记保留原年份、周编号和独立来源类型，包括非 ISO 编号的第 53 周；不推测它的日历日期。
- 修复重复导入时预览持有事务、版本读取再次写库导致的数据库锁定。
- 修复 CSV 导出往返的正文列识别、带引号和换行的长正文解析，以及周记来源和标签恢复。
- Markdown 导出包只解析实际条目，不把说明文件和 manifest 当作日记；周记导出保留周编号。
- 统一 Windows 混合换行，避免保存和重复导入反复增加空行。
- 历史问答及有日期范围的检索排除日期未确认的周记；无日期范围仍可检索周记。
- 修复技能检索把词频数字当作检索词的问题；非法保存参数返回 HTTP 400。
- 修复落笔进入导出或版本页后仍保留沉浸模式、隐藏导航及关闭按钮的问题；退出时保存待处理草稿并释放布局和日历事件。
- 新增可复用的隔离档案验收工具，确认目标服务与测试副本一致、远程 AI 关闭后才执行工作流。

九条流程包括：逐篇读取日记和周记、六组关键词检索、全日期日历、编辑原日记后恢复版本、附件读取及选中导出、本地问答证据与历史截止日期、导入后清除、全量备份恢复、恢复后重建派生索引。恢复流程逐份比较文件校验值。

浏览器另外操作了：流年上一页/下一页、首尾页跳转、周记及年份筛选、目录跳转、原页编辑与预览、保存后恢复原文件、全量导出范围、导入和版本入口、阁楼主题筛选与加载更多、原文侧页与完整来源跳转、整理类型筛选、技能变化图表及数据表、AI 关闭状态、雨声播放及森林声音切换和暂停、纪念页候选列表。流年根页面无滚动，长文在书本内滚动。

远程 AI 生成、云同步和纪念页公开发布使用隔离模拟回归，未将本次私人正文发送到这些服务。诗页检查了未配置 AI 时的状态；桌宠渲染、动作与单宠逻辑由现有自动回归覆盖。页面渲染检查不等于逐一执行每个工具的所有业务分支。

## 复现

```powershell
python scripts/audit_user_archive.py <日记压缩包.zip>
python scripts/audit_user_archive.py <日记压缩包.zip> --serve --workspace <报告中的隔离目录> --port 8792
python scripts/audit_user_archive.py <日记压缩包.zip> --check --workspace <隔离目录> --base http://127.0.0.1:8792
python scripts/audit_user_archive.py <日记压缩包.zip> --workflows --workspace <隔离目录> --base http://127.0.0.1:8792
python scripts/run_v04_release_checks.py
```

工作流会修改隔离副本，再恢复原正文，并保留测试产生的历史版本和备份。它不会把日记自动安装到正常使用的档案中。

本机报告：`docs/qa_private_archive/report.json`、`ui-final.json`、`ui-workflows.json`、`desktop-window.json`；自动回归报告：`docs/qa_v04/checks.json`。这些文件及安全设置截图均不进入 Git。
