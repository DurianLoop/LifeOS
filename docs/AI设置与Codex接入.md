# AI 设置与 Codex 接入

桌面端从左侧栏底部 **AI 设置** 进入；移动端从 **更多 → AI 设置** 进入。

## 模型 API

选择服务商，填写 **API Key**，点击 **保存并测试** 即可。DeepSeek、Qwen、GLM、OpenAI 和 Anthropic 的地址、默认模型及接口格式自动匹配；不用猜测密钥所属的服务商。Qwen 请选择开通密钥时对应的中国大陆、国际或美国区域。

需要网关地址、账号专属模型或不同接口时，展开 **自定义服务** 修改。选择「自定义服务」时必须填写地址与模型。新版区域工作空间地址也可在此设置；不会将密钥依次发送到其他区域尝试。

密钥通过操作系统凭据库保存；不可用时使用原有本机存储。页面不回显密钥，空输入保留原密钥。启用 AI 后，只有对应功能主动发起请求时才发送本次输入。连接测试只发送简短测试文字，不发送日记。

## 跟随 CC Switch

仅在检测到本机 CC Switch 配置或安装，以及 Codex CLI 时显示这个选项。选中并保存后，使用 CC Switch 当前写入 Codex 的连接，模型和地址不用再次填写。后续在 CC Switch 切换连接，LifeOS 的下一次调用跟随新配置。

没有检测到时只显示 API 方案。若已检测到但 Codex 尚未完成登录，连接测试会给出提示；先完成 Codex 登录再测试。既有 API 用户的明确选择会保留，不会因为暂时缺少密钥而自动改成 CC Switch。

检测只查看 CC Switch 数据文件是否存在，以及官方的目录覆盖设置；不读取其服务商数据库、日志或备份。仅有 Codex 配置不代表装了 CC Switch。Codex 调用不启用工具或附加整个日记目录。

## 功能开关

「功能设置」收起显示，展开后可分别管理人生问答、以前的我、AI 文言化与桌宠聊天，也可设置证据预览和缓存。每日一诗的内容与展示在「今日一诗」页面管理，不放进 AI 设置。

写作、搜索、统计、白噪音和规则分析不依赖文本模型。关闭 AI 后仍可使用这些功能，并阅读已有诗句。

公开纪念页的访客分身由线上服务独立配置，本机密钥不会自动用于公开站点。请在纪念页中管理公开内容与分身，再发布更新。
