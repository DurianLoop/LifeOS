# 拾诗、旧笺与记忆抽签机验收

2026-10-07，基于现有 v0.5.1 源码完成界面和功能调整

- 诗文模式统一使用「拾诗」「旧笺」，导航、页面标题和产品指南一致，旧名称仍可检索
- 抽签支持旧页、回声、线索，优先显示可打开的真实来源，避开最近抽过的结果
- 抽签打开成功后保留本机彩笺；书页、书签与目录同步显示，刷新后保留，点击彩笺可取消
- 彩笺只记录来源路径，原始日记正文不受标记操作影响；读取或写入失败不覆盖已有记录
- 灵犀去掉重复的页面边距，宽屏展开，窄窗保留 18 px 页边距，宠物图像与文字不重叠
