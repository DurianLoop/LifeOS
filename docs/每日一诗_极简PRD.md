# LifeOS「今日一诗」极简 PRD

**目标：**让每天的真实经历遇见一首值得记住的诗。打开即可读，不设背诵任务。

## 1. 入口与位置

- 侧边栏新增独立板块「今日一诗」，**固定放在「寻迹」与「昔日今朝」之间**。
- 板块首页展示当天推荐，另有一个轻量「诗词库」入口，可按日期回看过去所得。
- 开启自动生成后，当天第一次保存有内容的日记便生成一首；保存成功后可从「今朝」的小入口直接打开，也可从侧边栏进入。后续修改同一天日记，不自动换诗。
- 首次开启自动生成时，明确说明当天日记会发送给用户已配置的 AI；授权一次即可，不在每天保存时反复打断。未开启自动生成时，板块提供「生成今日一诗」按钮；AI 未配置时提示先完成配置。

## 2. 三种展示形态

| 形态 | 展示内容 | 出现位置 |
| --- | --- | --- |
| ① 一句诗 | 名句＋作者＋篇名 | 「今日一诗」首页的默认样子；安静、易记 |
| ② 一整首 | 原作全文＋作者＋篇名＋对应注解 | 「诗词库」中点击该日作品后的详情页 |
| ③ 一句诗与缘由 | 形态①＋「为何是它」 | 首页点「看缘由」后原位展开，不跳弹窗 |

「为何是它」为约 50～100 字、易读的短篇文言：点出日记中的真实经历或心绪，再与诗人创作时有据可查的处境相照。诗人经历缺少可靠资料时，只解释诗意与当日经历的联系；不得编造生平或把推测写成用户事实。

## 3. 推荐与诗词库

- 先收录一小批**经过校对、偏热门、容易记住**的诗词，保存全文、名句、作者、篇名、注解、可靠背景与主题标签。
- 本地从尚未推荐的作品中筛出候选，AI 根据当天日记选一首并写缘由。诗句、原文、注解与作者信息只取自诗词库，AI 不自行生成。
- 每天最多自动生成一首；同一天反复打开结果不变，不重复调用 AI。生成成功即按日期入库，记录的是「当日所得」，不推断用户已经背会。
- 按**整首作品**去重：即使换一句名句，日后也不再次推荐同一首。候选耗尽时提示可回看，不暗中重复。

## 4. 最小实现与验收

复用现有 AI 配置和日记保存流程；只新增侧边栏入口、今日展示页、诗词库详情页，以及本地的诗词数据与每日推荐记录。结果留在本机，不改写原日记。生成失败时保留手动重试入口，不占用当天名额。

**验收：**侧边栏位置正确；保存日记后当天只生成一次；首页能在形态①与③之间展开/收起；诗词库提供形态②；作品不重复；未授权自动生成时不会自动发送日记。
