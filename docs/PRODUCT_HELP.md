# 灵犀中的产品使用指南

v0.5 源码预览中的灵犀对话支持询问 LifeOS 的现有操作，例如「怎么调整侧边栏，把每日一诗收进阁楼」「导入后怎么清除测试数据」或「怎么让桌宠重复一个动作」

产品指南保存在随应用打包的 `config/product_help.json`，当前版本为 `0.5.0-help.3`，包含 162 张功能卡，覆盖基础注册表的 141 个功能及侧栏、外观、档案操作。内容根据当前源码核对，明确区分正式功能、候选统计和未完成能力

## 按需检索

每次以当前用户问题为主进行本地检索，最多取 3 张相关卡片，正文总长不超过 5,600 字符。明确的短追问可沿最近产品主题继续；普通闲聊或个人经历问题不会附加产品资料，换话题会中止继承。检索不读取日记、索引、API Key、当前页面或桌面事件，也不联网

启用且配置了桌宠聊天时，当前对话与本轮相关片段交给共享模型路由。模型需要这些片段才能解释操作，但整本手册不会常驻提示词，也不会追加到长期聊天记录；不要求提供商支持原生工具调用或向量接口。API、Responses、Anthropic、Codex 和云端模式沿用现有权限与配置，仍使用 `Pet Companion` 功能许可

未配置模型或关闭 AI 时，产品问题返回明确标示的本地指南，不调用模型；普通闲聊维持原来的 AI 配置要求。模型失败仍返回可重试的错误，并附上已检索的本地步骤，界面可以在错误后显示它们。对话和指南片段均不进入 AI 答案缓存

## 来源与导航

回复附有本轮指南来源及版本，来源按钮只导航到当前存在的功能。来源的 `feature`、`action` 来自固定本地卡片，模型回答不能创建动作、执行修改或打开任意网址。导入回滚、恢复备份、公开纪念页等操作仍由用户在原界面确认

只读接口 `GET /api/help/search?question=...` 返回 `knowledge`、本地 `text` 和 `remote:false`。`POST /api/pets/chat` 的 `mode` 为 `companion`、`product_help` 或 `local_guide`；模型错误使用 HTTP 502、`mode:llm_error`，并可附 `local_guide`

## 维护与验证

新增或改变功能时更新对应卡片的入口、正文、别名和检索意图，并递增 `version`。知识库从 `LIFEOS_RESOURCE_ROOT` 下的应用资源读取，不读取工作区里用户可修改的旧配置；桌面资源打包已有完整 `config` 目录

运行 `python -X utf8 scripts/test_product_help.py`。12 组专项检查覆盖功能清单与来源路由、中文与英文操作检索、个人问题边界、连续追问及话题切换、所有共享模型接口、功能权限、本地指南、模型错误和旧聊天契约。检查使用空隔离工作区和模拟传输，不读取真实日记或发送远端请求
