# LifeOS v0.4.3

漂流瓶是写给未来自己的时间来信，入口位于左侧灵犀上方

- 写文字、录声音或视频，也可以选择已有媒体
- 自定开启日期和时间，提供一周、一个月、一年后的快捷选择
- 月海、晨雾、暮色三种离线背景，信纸与玻璃瓶的封存、重逢体验
- 细化玻璃瓶、信纸、海面光影与卡片，背景切换柔和过渡
- 封存时信件收起随瓶漂流，抵达时拆信展开，支持系统减少动态效果
- 八组随机写信提示，草稿的提示保持稳定，可一键换个灵感
- 大部分页面滚轮位于窗口关闭按钮下方且右边界对齐，信件和导入导出窗口同样采用独立滚动区
- 草稿自动保存，录制离开时收尾，权限失败可选文件，上传失败可重试
- 封存后不能修改或提前开启，列表不返回正文，媒体接口也校验开启状态
- 到期显示侧栏角标与应用内提醒；桌面应用运行时发送系统通知，重新打开应用补查错过的来信
- 漂流瓶与媒体纳入工作区备份，旧时间胶囊自动迁移到持久存储

单个媒体文件限 100 MB，一次录制最长 10 分钟。时间使用设备时钟，显示为当前设备的本地时间。漂流瓶保存在本地工作区，不调用 AI，不进入日记检索或纪念页。备份可包含封存内容，应像日记备份一样妥善保管

## 验收建议

1. 进入漂流瓶，写信并切换背景，关闭再打开确认草稿保留
2. 录一段声音和视频，预览后封存；也试一次已有文件上传
3. 把开启时间设为几分钟后，尝试提前开启，最小化应用等待提醒，再拆封
4. 重启应用，检查草稿、已封存与已开启的内容；在隔离工作区验证备份恢复

录音、录像已用 Electron 的真实 MediaRecorder 与虚拟设备验证，仍需要在你的实际麦克风、摄像头和系统通知设置下验收
