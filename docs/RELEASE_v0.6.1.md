# LifeOS v0.6.1 · 随身体验修订

手机端过去主要缩放桌面布局，功能藏得深，悬浮伙伴还会挡住导航。现在 Android 与 iOS 使用五项主导航，并可按用途或关键词查询完整功能目录。导入、导出、版本、备份恢复、隐私、AI 与外观有明确入口；写作分格改为单列，数据工作区使用完整屏幕。

原生应用继续运行完整桌面业务引擎，资料、附件、修订与备份位于设备私有工作区。新手机导航不改变桌面导航配置，也不清理已有档案。

官网手机网页同步完成独立重构：六格写作、周记、附件、多草稿、历史恢复、记忆抽签、时间信件、诗选、ViVi 与 DSH 小鲸、自然声、导入预览和加密完整备份。网页与原生应用的数据独立；网页尚不具备完整桌面分析引擎和自动同步。网页源码维护在 `codex/pocket-completeness` 分支。

## 交付

- Windows 安装包，macOS Apple Silicon / Intel 原生 DMG 与 ZIP。
- Android APK；保留同一发行签名以支持覆盖更新。
- iOS 源码和 Apple Silicon 模拟器构建；不提供 iPhone 签名包或 TestFlight。

## 验收

发布前要求本机数据库/附件/加密备份/恢复与重启测试、手机导航可达性及遮挡检查、所有现有页面的 390/768 布局检查、macOS 两架构安装包验证，以及 Android/iOS 实际系统 WebView 验收。记录保存在随发行附带的验证文件中。合成验收资料不进入分发包；不以渲染页数代替写作、重读或备份操作。

API 密钥、真实个人日记与本地签名密钥均不进入源码和安装包。DSH 动画禁止商业使用，来源 https://github.com/PC2005-cloud/dsh-pet 。
