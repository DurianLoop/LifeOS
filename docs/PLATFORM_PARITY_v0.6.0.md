# v0.6.0 平台验收范围

macOS 使用完整 Electron 桌面应用，分别构建 Apple Silicon 和 Intel 安装包。
Android、iOS 使用原生 WebView 与随包 CPython，在应用私有目录运行相同的
前端、Python 业务代码和数据引擎。手机端不依赖电脑启动服务。

| 内容或操作 | Windows / macOS | Android | iOS 本轮交付 |
| --- | --- | --- | --- |
| 原有页面、日记、周记、阅读、检索与档案观察 | 完整应用 | 完整应用 | 完整应用 |
| 写作、历史版本、附件、导入预览与回滚 | 本地引擎 | 相同本地引擎 | 相同本地引擎 |
| 草稿、布局、字体、侧栏、伙伴偏好 | 工作区持久化 | 私有工作区持久化 | 私有工作区持久化 |
| 加密、备份、恢复与重建 | 本地执行 | 本地执行 | 本地执行 |
| 诗歌、抽签、漂流瓶、白噪音与应用内伙伴 | 保留 | 保留 | 保留 |
| DSH 小鲸 106 段动作 | 原版 WebM | 从原版生成的透明图集播放 | 从原版生成的透明图集播放 |
| 导入文件 | 系统选择器 | Android 文档选择器 | iOS 文档选择器 |
| 下载、导出 | 系统文件保存 | Android 文档提供器 | iOS 分享面板 |
| 网络 AI、Ollama 局域网服务、同步与主动公开 | 按用户配置 | 按用户配置 | 按用户配置 |
| 桌面悬浮伙伴、托盘、关闭到托盘、桌面更新器 | 保留 | 应用内伙伴；手动安装 APK | 应用内伙伴；本轮模拟器构建 |
| 本机 Codex / CC Switch 等桌面可执行程序 | 桌面环境可用 | 使用已配置的网络模型端点 | 使用已配置的网络模型端点 |
| 到期漂流瓶 | 桌面运行时提醒，重启补查 | 打开应用时补查 | 打开应用时补查 |

iOS 按本次交付要求仅提供源码和 Apple Silicon 模拟器应用，不提供签名
iPhone 安装包，不提交 TestFlight。系统后台运行、托盘、桌面程序接入的
差异由操作系统能力决定，不能用“全平台”表示这些桌面能力在手机上存在。

发布验收使用合成日记和隔离工作区。业务回归、原生页面与动画检查、
附件字节、加密依赖、持久化和备份恢复的结果随发行报告提供。
网络服务需要用户自己的有效配置；模拟器测试不代表所有实体设备型号
以及未配置的第三方服务都已逐一验证。

Android 签名私钥保存在发布者本地，构建仓库与 CI 不接收私钥或密码。
应用升级应继续使用同一签名，并保留包名与私有数据目录。
