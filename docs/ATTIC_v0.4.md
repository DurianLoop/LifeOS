# v0.4 阁楼

阁楼从工具入口改为连续阅读的四个分组，版式沿用 v0.4 的纸张、字体、配色、窗口栏和侧栏。

| 分组 | 已实现 |
| --- | --- |
| 概览 | 主题的首次与最近原文、按实际日期定位的时间轴、项目/问题/决定原文线索、月度写作记录 |
| 回看 | 按主题与年份筛选日记、分页、摘录、年度回顾入口 |
| 整理 | 按项目/问题/决定及年份筛选线索、原页预览、同主题的后续记录、原整理工具入口 |
| 观察 | 年/月写作统计、当月原页、技能记录来源、原观察工具入口 |

侧栏分组可收起；窄屏从“更多”进入。页内目录跟随阅读位置，原页在右侧展开，可返回来源列表或进入流年。切换分组保留各自的筛选、已经加载的记录和阅读位置。工具索引从现有功能注册表生成，当前包含 139 项，支持中文名称及原英文名称搜索。

## 数据规则

- 新接口只读取本机 SQLite 索引，不调用 AI、不修改日记。
- 只统计有非空正文段落、日期正常的日记；写作日按不同日期计数，同一天的多页单独计入页数。
- 主题来自现有词语索引，显示对应原文与真实日期。只有一页时显示一份原文；同一天的时间轴节点合为一个。
- 项目、问题和决定来自现有原文候选；相同触发词不会自动把不同记录合并为一个项目。
- 决定的后续只展示 30 天内同主题的真实记录，不判断是否执行或是否造成某个结果。
- 概览的主题对照覆盖完整时间跨度，年份选择作用于月度记录。回看和整理支持全部年份。
- 无记录月份禁用翻阅；读取失败可重试；原页失效时显示打开失败。
- 技能页展示有来源的记录页数，不把提及次数换算成能力评分。

候选确认、合并与拆分、手动标签、收藏及 AI 语义分析属于后续工作。原工具经索引进入各自的已有页面。

## 本机验收

`python scripts/run_v04_release_checks.py` 通过 29 组回归检查，其中 `scripts/test_attic.py` 的 7 个用例覆盖空档案、同日多页、异常日期、单页主题、原文别名、分页筛选、来源和参数边界。`scripts/test_archive_charts.mjs` 的 6 个用例覆盖四个实际页面、有/无记录、失效技能、月份间隔、异常值、文本转义和词语切换。全量档案验收见 [PRIVATE_ARCHIVE_ACCEPTANCE.md](PRIVATE_ARCHIVE_ACCEPTANCE.md)，AI 来源对照评审及检索修复见 [AI_QUALITY_ACCEPTANCE.md](AI_QUALITY_ACCEPTANCE.md)。

桌面后端测试在隔离用户目录中验证了空用户启动、新日记保存后立即出现在阁楼、月份检索及重启后保留。浏览器验收使用 41 篇虚构日记和独立空用户目录，没有读取私人日记。

浏览器已验收：多主题切换、单页旅行主题、全部年份的 41 页分页、2024 年的 2 页筛选、决定原文与后续来源返回、流年返回位置一致、空月份禁用、2023 年/月传递到观察、工具中英文搜索和无结果状态、侧栏收起、空用户写作/导入、390 × 844 窄屏及侧层。

测试场景中分页展开后，切换分组再返回仍保留 41 页和 `3556px` 的阅读位置；从流年返回概览的阅读位置保持一致。窄屏根页面宽度和内容宽度均为 `390px`，没有横向溢出。

## 顶部与图表修复验收

阁楼顶部在滚动前后保持同一字号和高度，背景覆盖整个内容区。布局首列与实际侧栏宽度一致，消除旧样式留下的 26px 空隙；页内跳转按顶部实际高度定位。概览使用四格图标，与阁楼分组区分。

补齐原来缺失的 `lineChart`，技能证据、技能变化、写作统计、词语变化全部显示来自本机索引的 SVG 月度图表与可展开数据表。月份按实际时间间隔排列；零值、单月、空档案均正常。技能与词语可以切换；技能来源标记保存后立即更新数量、进度及筛选，并在刷新后保留。

浏览器使用隔离的 41 页虚构日记与空用户目录，已验收四个模块、阅读/无记录词语切换、技能标记与筛选、来源跳转、月度数据表、宽窗口、侧栏收起/展开、390 × 844 窄屏。桌面顶部始终为 44px 字号、约 79.67px 高度；窄屏为 34px 字号、约 66.67px 高度，页面宽度 390px，无横向溢出。

## 可复现预览

```powershell
python scripts/preview_attic.py --port 8785
python scripts/preview_attic.py --port 8783 --empty
```

打开 `http://127.0.0.1:8785/#Attic` 查看虚构日记场景；`8783` 为无日记的首次使用场景。普通源码启动使用产品自己的本机数据，不加载这些验收样例。
