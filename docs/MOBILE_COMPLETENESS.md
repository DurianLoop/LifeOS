# 手机体验补全与验收

## 发现的问题

v0.6.0 的原生应用复用了桌面业务引擎，但适配主要依赖样式覆盖。
官网 `/app/` 仍是独立 v0.1 文字日记，不能据此声称手机网页版已全量迁移。
页面存在、渲染无溢出、API 单项测试通过均不能代替完整任务验收。

## 本轮交付目标

保持现有纸张、书页、松绿与暖白视觉；正文可读，控件可触，减少层层寻找。
旧版浏览器记录必须原地升级，不更换数据库名，不静默覆盖草稿或冲突原文。

| 工作流 | 手机网页版补齐 | 验收依据 |
| --- | --- | --- |
| 写作 | 日记/周记、六种纸格、标签、附件、自动草稿、版本恢复 | 创建、修改、刷新、恢复原版本 |
| 翻阅与寻找 | 日历、日记/周记筛选、标签、收藏、原文阅读与附件下载 | 从搜索/抽签/阁楼跳转同一原文 |
| 档案 | 年/月覆盖、写作节律、往年今日、标签、来源入口 | 合成档案的统计与日期对照 |
| 记忆抽签 | 旧页/回声/线索、避开近期、历史与原文 | 三种模式连续抽取与来源核对 |
| 漂流瓶 | 文本与媒体、日期封存、到期、已开启 | 未到期保持封存，到期可开启 |
| 拾诗 | 本地诗选、收藏、按日记选材与可选 AI | 离线可读、AI 只发确认内容 |
| 伙伴与声音 | ViVi 与 DSH 106 段动作、聊天、真实自然声、音量与定时 | 明确播放状态、切换/暂停/定时 |
| 数据 | JSON/Markdown/TXT/HTML/CSV 导入预览、冲突策略、完整附件备份、加密备份 | 空库往返、逐字节附件、错误密码、不覆盖冲突 |
| 设置 | 字体/字号/行距/主题、存储管理、AI 与安装 | 刷新后偏好、错误状态和取消 |
| 原生端 | 手机导航、全功能入口、写作/阅读/数据管理触摸布局 | 实际核心任务验收及截图 |

浏览器无法替代桌面系统托盘、悬浮窗或本机进程集成。同步使用明确的数据交换流程，
不能把文件导入导出标成已完成自动同步。没有实机或真实服务配置的项目如实记为未验收。


## v0.6.1 验收记录

- 网页 46 项自动检查：真实 IndexedDB v1 升级、事务回滚、并发编辑保护、完整附件往返、草稿/信件、AES 错误密码和篡改、ISO 周记、ZIP CRC/路径、网关边界、离线缓存与音频范围请求，以及完整备份重新导入时识别相同历史与真实的历史正文变化。
- 浏览器合成流程：创建六格日记 → 保留草稿 → 刷新续写 → 添加附件 → 保存重读 → 编辑 → 恢复旧版本 → 导出文件 → 在空白来源预览导入 → 重读附件和历史。
- 浏览器实际生成密码备份，错误密码拒绝且原文不变；正确密码解密后预览附件、信件与历史。相同备份恢复跳过原记录，不误报冲突，也不增加重复历史。
- 停止本地服务后刷新应用，播放已缓存雨声，创建周记并保存，再刷新重读原文。
- 在真实旧版页面创建已保存记录与未完成草稿，替换静态发行后关闭旧页；新版保留两者，正文逐字一致。核心资源安装绕过浏览器旧缓存，更新等待旧页关闭。
- 320/430/768 像素下检查记忆抽签、漂流瓶、诗选、阁楼、人生问答、设置；均无页面横向溢出。另检查 320 像素的写作和阅读对话框。
- 三种抽签模式与回原文、诗选收藏刷新恢复、外观刷新恢复、时光信草稿/未到期/到期打开/已读筛选、自然声播放/定时/暂停、AI 选材预览与取消已操作验证。未向真实模型发送验收资料。
- DSH 全部 106 段 WebP 的 12,659 帧完成解码和透明通道检查；浏览器抽查写代码、蓝鲸现世及开心跃动。

尚未将桌面浏览器验收等同于 iPhone Safari 实机验收。浏览器麦克风录音、iPhone 安装与真实付费模型调用仍需要相应设备/服务；iOS 原生交付范围维持源码与 Apple Silicon 模拟器。网页不宣称已迁移完整桌面分析引擎或自动同步。
