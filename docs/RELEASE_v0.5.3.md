# LifeOS v0.5.3

让每一页更好读，也让灵犀多一位伙伴。

## 字号与排版

- 全局统一正文、标签、辅助信息与标题层级，覆盖今朝、流年、落笔、寻迹、拾诗、旧笺、漂流瓶、灵犀、AI 设置和阁楼工具。
- 默认界面文字 16px，阅读正文 18.5px，辅助文字以 13px 为基准；保留舒展、书卷、紧凑风格及舒适、大字、特大设置。
- 修复嵌套文字反复乘字号倍率的问题；标题比例更克制，行距与段落间距统一，长文保持适宜阅读宽度。
- 侧栏、表单、按钮、日记目录与日期控件同步调整；窄窗中操作区换行，避免大字挤压控件。

## DSH 小鲸

- 内置上游 106 个透明动画，保留原始视频、动作权重、文字朝向和完整单次播放。
- 支持点击回应、拖动反应、暂停动效、桌面模式以及离线恢复安装。
- 原作者：[PC2005-cloud/dsh-pet](https://github.com/PC2005-cloud/dsh-pet)。代码使用 MIT；动画、提示词和源视频禁止商用，发布和展示保留署名与来源链接。详见 [授权说明](DSH_PET.md)。

## 发行

Windows x64 安装包包含 Python；macOS 提供 Apple Silicon 和 Intel 原生构建，沿用原生运行时、签名与打包验证流程。升级保留独立的本地资料库。

源码和安装程序从独立的空资料库发布目录构建，不包含个人日记、凭据、设置或验收截图。检查报告与安装包校验值随 Release 提供。
