# LifeOS v0.5.0

让侧栏只留下自己常用的功能，让第一次打开更轻松

## 自定义侧栏

- 从「界面微调 → 编辑侧栏」进入编辑
- 拖动调整先后顺序，拖进阁楼收起，也可从阁楼拖回
- 阁楼可展开或折叠，收起的功能仍然可以使用
- 「完成」才保存；「取消」放弃本轮更改；「恢复默认」也可在保存前取消
- 侧栏排列和阁楼展开状态保存在本地工作区，重启及更换端口后保留
- 设置保持独立入口，即使所有功能都收进阁楼也可进入
- 窄窗口通过「更多」访问全部功能，编辑时展开侧栏；支持鼠标、触摸和键盘
- 条目浮起后图标和名称跟随指针，其他条目平滑让位，放下后归位；减少动态效果时关闭过渡
- 顶部收起与展开按钮放在页面标题左侧，品牌区和整个侧栏一起收起，重启后保留状态
- 窄窗口保留底部导航，编辑期间侧栏展开，切换窗口尺寸也能继续编辑
- 灵犀使用猫咪图标，视觉世界说明压为一行
- 白噪音采用 16 像素动态音量轨道与播放、暂停、载入取消图标，保留 42 像素操作区域

键盘编辑：上下箭头排序，左箭头放回侧栏，右箭头收进阁楼，Escape 取消

## 灵犀资源目录

- 对照 awesome-codex-pet 的 `4672bd7e` 提交更新来源快照，305 项元数据中展示 268 项许可支持的资源
- 目录分批加载，可继续翻阅全部资源，搜索和分类不受原先 120 项上限限制
- 首次打开优先读取本地快照，点击「更新目录」才联网；更新失败可重试，保留已安装资源和当前选择
- 支持原有与 v2 图集，下载安装保留作者、许可和上游来源
- 默认两列，更新目录左侧用图标切换一列、两列、四列；选择在本机保留，窄窗口自动适配
- 当前桌宠、已安装角色及目录预览都可右击选择循环动作；每只角色独立，选择「恢复自动」回到事件互动
- 移除集中互动动作区域；右键菜单也支持键盘及触屏长按，关闭动画时暂停播放
- 未安装角色只在选动作时读取公开图集，不改变当前桌宠或执行安装；读取失败可以重试
- 已安装桌宠都可以移除，包括 Desk Otter；移除记录在重启及升级后保留，再从宠物库添加可恢复

## ViVi 与桌面陪伴

- 接入 ViVi Diary 的独立 GIF 渲染器，保留 14 个原始动画和左右行走等 16 个动作选项
- 长动作完整播放，保留自动游走、跳跃、拖动反馈、靠边藏起和点击走出
- 灵犀标题右侧齿轮统一管理软件内或桌面显示、显示开关、置顶、大小、播放动效和关闭窗口后保留
- ViVi 额外提供自动游走、靠边藏起与四种拖动动作设置
- 桌面模式收起软件内悬浮宠；关闭主窗口可继续桌面陪伴，托盘可重新打开 LifeOS、调整桌宠或完整退出
- 完整退出和更新安装仍检查草稿保存，再结束桌宠与后台；桌宠不读取日记
