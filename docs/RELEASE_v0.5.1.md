# LifeOS v0.5.1

ViVi 更自然地陪伴，AI 可以连接本机已经下载的 Ollama 模型

## ViVi 与桌宠

- 自动行为随机选择姿态、短动作与游走，避免连续重复，预览保持在卡片内
- 右键选择的动作完整执行一次后恢复自动，再次选择可以重新播放
- 暂停、拖动、缩放保留动作进度，切换页面或显示模式不重播旧指令
- 保留原始 GIF 的帧数、时长和停顿，共享缓存减少重复下载和解码
- 左右靠边藏起时正确露出尾巴，大小通过细滑条调整

## Ollama Demo

- 在 AI 设置中选择 Ollama，读取本机已经下载的模型
- 默认连接本机 Ollama，选择模型后保存并测试连接，无需 API Key
- 当前 AI 功能复用相同入口、独立开关和选材确认
- API 与 Codex 配置继续保留，切换使用方式即可选择
- Ollama 服务未启动或没有模型时显示可操作的状态，可重新检测
- 模型需要提前在 Ollama 中下载，安装程序不附带或自动下载模型

## 搜索与恢复

- 宠物库增加清除入口，点击 × 或按 Escape 恢复默认分类和列表
- 寻迹清空时重置筛选与返回上下文，取消过时请求，旧结果不会再次出现
- Windows 清除已提交的导入或回滚时，通过重启完成恢复，避免正在运行的数据库占用导致失败
- 恢复完成后再清理导入任务与临时文件，中断后可以继续，重启前会检查草稿保存
