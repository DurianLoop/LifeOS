# LifeOS v0.5.2

重逢旧日，给抽中的一页留下彩笺

## 记忆抽签机

- 旧页、回声、线索三种抽法，结果附带原文入口
- 新保存的日记可以立即抽取，连续抽取避开近期结果，抽完后重新开始
- 展开原页后留下彩色书签，书页和目录同步标记，重启后保留，点击彩笺可以取消
- 返回抽签保留当前结果，连点不会重复请求，失败后可以重试
- 彩笺保存在本机，只记录来源路径；保存失败不会覆盖已有标记

## 界面

- 诗文模式中的今日一诗与昔日今朝统一为「拾诗」「旧笺」
- 侧栏诗文字体与字号统一，白噪音播放按钮缩小，细滑条播放时流动
- 灵犀去掉重复的页面留白，宽屏展开，窄窗保留页边距，宠物预览与文字正确对齐
- 抽签界面沿用纸张风格，支持窄窗与减少动效设置

## 验收与发行

Windows x64 安装程序包含 Python，升级保留本地工作区

602 篇真实日记的隔离副本通过原文、来源、跳转及抽签去重检查。真实日记、凭据和验收工作区不包含在源码或安装程序中

详细检查结果和安装包校验值见 Release 中的 `RELEASE_VALIDATION.json` 和 `SHA256SUMS.txt`
