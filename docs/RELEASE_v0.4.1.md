# LifeOS v0.4.1

延续 v0.4 的纸张与书本界面，完成阁楼页面、导入导出和 AI 证据流程的修复与升级。

- **阁楼**：概览、回看、整理、观察采用连续阅读布局，支持筛选、分页、原文预览和阅读位置保留；修复滚动顶部异常，补全写作统计、技能证据与词语变化图表。
- **日记**：改进 Markdown 日期和周记识别、换行与往返导入，完善导入、导出、预览和清除流程。
- **AI**：发送前确认所选证据，支持失败重试；修改问题、截止日期或原文后重新确认，避免旧结果混用；保留引用与来源的对应关系。
- **检索**：优先匹配明确主题，完整日期限定到当天，“截至某日”保留更早记录；时间顺序与过去视角的证据范围更准确。
- **纪念页**：公开问答仅使用选中的快照，完善引用、超时、额度、空答案与上游错误处理。

保留每日一诗、离线自然白噪音、书本阅读、自由调整纸格和统一 AI 设置。AI 可使用用户配置的模型 API，或本机已安装并登录的 CC Switch/Codex。

本版通过 29 组自动回归。精选真实日记问题另外进行了模型回答与原文对照；评估范围和限制见 [AI_QUALITY_ACCEPTANCE.md](AI_QUALITY_ACCEPTANCE.md)。

Windows 安装包内置 Python，首次启动创建空白工作区。升级保留现有本地日记与设置；安装包和仓库不包含私人日记、测试副本或密钥。

下载 `LifeOS-Setup-0.4.1.exe`。`latest.yml` 和 blockmap 用于桌面更新，`SHA256SUMS.txt` 提供校验值。本社区构建未签名。
