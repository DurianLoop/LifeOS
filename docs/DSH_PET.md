# DSH 小鲸

在「灵犀 → 已安装」选择 **DSH 小鲸**。右键角色可以选择全部 106 个原版动作；设置中的显示位置、大小、置顶、关闭窗口后保留和动效开关沿用 LifeOS 的桌宠设置。

动画使用原始透明 VP9 WebM，保留原版随机动作分类、权重、点击回应、转向、移动参数与拖拽姿势。点选动作完整播放一次后恢复自动陪伴。文字动作保持原始朝向。聊天使用 LifeOS 现有的聊天入口与 AI 设置。

原作：[PC2005-cloud/dsh-pet](https://github.com/PC2005-cloud/dsh-pet)。固定版本为 `15e59d2a42fa0d674720dd813480bc7aea786e86`，106 个动画共 54,351,332 字节，未转码，文件映射及 SHA-256 记录在素材包的 `pet.json` 中。使用 `scripts/sync_dsh_pet.py` 可从固定版本重新校验并获取素材。

原作代码为 MIT；**动画、提示词和源视频允许开源使用，禁止商用**。原作者要求在介绍、展示及分发衍生作品的地方附上原作 GitHub 地址。LifeOS 的宠物库、角色提示和桌面动作菜单保留此来源，素材包中附有原作许可和声明。商业发行须先取得原作者对素材的额外授权。

验证：`scripts/test_dsh_pet.py` 校验素材哈希、许可、原版动作池和离线移除恢复；`scripts/test_dsh_pet_electron.cjs` 在隔离空工作区检查真实宠物库、106 个视频解码、透明通道、完整播放、拖动、暂停恢复及独立桌宠窗口。验收结果和截图写入忽略发布的 `docs/qa_dsh/`。
